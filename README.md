# Bar Chart with Variation %

A Power BI custom visual that displays bar charts in a **Small Multiples** layout, with automatic variation % labels and bracket connectors between consecutive bars.

## Features
- Small Multiples grid (one panel per dimension value)
- Variation % with ▲/▼ arrows and bracket connectors
- Shared Y scale across panels
- Free / Pro tiers via Microsoft AppSource licensing

## Data Roles
| Field | Role | Required |
|---|---|---|
| Axis | X-axis labels within each panel | Yes |
| Small Multiple | Creates one panel per value | No |
| Values | Numeric measure | Yes |
