WHAT CHANGED IN 1.10.0.0
1. THREE REFERENCE MEASURES (Pro): Previous Year, Plan / Budget, Forecast. Bind one, pick
   it in Format > Comparison > Compare to, and every bar gets a horizontal marker at that
   level: the bar is the actual figure, the marker where it should be. Free keeps
   comparing against the previous category on the axis, as before.
2. ACCESSIBILITY AND LOCALIZATION, claimed before and not really there. The visual now
   reads colorPalette.isHighContrast and paints from foreground / background /
   foregroundSelected, so the Windows theme is honoured with nothing to turn on, and
   per-series and conditional colours stand down. The format pane is localized with
   displayNameKey, 95 keys in en-US and es-ES; there was not one key before, so the
   resource files were dead. host.allowInteractions is now respected.
3. Bar border colour and width, free, off by default. Drawn inside the bar, so a zero
   value stays on the baseline.
4. Fixed: the bar colour could not be set to the default blue - the default value was
   itself the "not configured" sentinel. Now read from metadata.objects. LinesColor,
   unused, removed.

FREE VS PRO
Free: bars, variation %, 3 panels, bar and border colours, sort, tooltips,
cross-filtering, legend, high contrast, es-ES.
Pro: the three reference measures, absolute variance, 100 panels, analytical lines and
band, value labels, per-bar colours.
