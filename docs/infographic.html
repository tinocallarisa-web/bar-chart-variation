Key Benefits

No formulas. Variation % is computed inside the visual — no DAX, no calculated columns.

Shared scale. All Small Multiple panels share the same Y axis for honest comparison.

Native integration. Cross-filtering, drill-down, slicers, and bookmarks all work out of the box.

Accessible. High contrast mode, keyboard navigation, and screen reader labels included.

Tips

Use Decimal Places = 0 for executive dashboards — clean numbers, no noise.

Set a Reference Line to your budget target. Bars above it are green, below are red.

Use Sort: Descending to instantly rank categories from best to worst.

Drag extra fields to Tooltips — add context like units or region without cluttering the chart.
