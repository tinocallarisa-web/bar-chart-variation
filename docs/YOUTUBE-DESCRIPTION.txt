>>> EMPIEZA AQUÍ >>>

A bar chart that compares each month against the one before answers "is
this month better than the last one". It does not answer the question the
meeting is actually about: are we on plan.

Bar Chart with Variation % now answers both. Bind Plan, Budget, Forecast or
Previous Year, and every bar gets a horizontal marker at the reference
level — the bar is the actual figure, the marker says where it should be.
It is the IBCS reading, and it takes no measure of your own: no DATEADD, no
date table, no variance column.

WHAT IS NEW IN THIS VERSION
• Three reference measures — Previous Year, Plan / Budget and Forecast —
  each drawn as a marker on the bar, and included in the Y scale so a plan
  above actual still fits in the panel.
• Small multiples you control: set the number of columns instead of
  accepting the automatic grid.
• Panel titles with a filled header, not just a separator line. If your
  title colour would not read against the band, it flips automatically.
• Bar borders, with colour and width, drawn inside the bar so a zero value
  still sits on the baseline.
• Real high contrast: the visual now follows the Windows theme with nothing
  to turn on, and the format pane is available in Spanish.
