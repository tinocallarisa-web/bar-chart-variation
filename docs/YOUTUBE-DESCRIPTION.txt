YOUTUBE DESCRIPTION — FULL VIDEO
==========================================

A bar chart that compares each month with the one before answers "is this month better than the last one". It does not answer the question the meeting is about: are we on plan. Bar Chart with Variation % writes the variance on every bar by itself and draws a marker where each bar should have been — your plan, budget, forecast or last year. No DATEADD, no variance column.

Get it on Microsoft AppSource: https://marketplace.microsoft.com/en-us/product/tino_callarisa.bar-chart-variation

WHAT IT DOES
──────────────────────────────────────────
✅ The variance % between bars, calculated for you, with arrows and brackets
✅ A reference marker for Plan / Budget, Forecast or Previous Year, with the variance on every bar
✅ Bars below their reference in the negative colour
✅ Small multiples on a shared scale, vertical or horizontal
✅ Six style templates, including an IBCS style, and a setup guide
✅ Labels that never overlap: on narrow bars they shrink or alternate heights
✅ Date and number axes in time order; empty future months hidden on request
✅ Click to filter, highlight, bookmarks, drilldown, keyboard navigation and high contrast
✅ The measure's number format, dynamic format strings included; twelve languages
✅ No network requests: everything is computed inside your report
